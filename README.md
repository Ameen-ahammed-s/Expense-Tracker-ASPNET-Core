# Expense Tracker ASP.NET Core MVC

A web-based Expense Tracker application built using ASP.NET Core MVC, C#, SQL Server, and Entity Framework Core.

## Features
- User Authentication
- Monthly Budget Management
- Expense Tracking
- Expense Categories
- Expense Analytics Dashboard
- Pie Chart Visualization
- CRUD Operations

## Technologies Used
- ASP.NET Core MVC
- C#
- SQL Server
- Entity Framework Core
- HTML
- CSS
- Bootstrap
